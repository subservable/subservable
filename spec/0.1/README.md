# Specification 
## Version 0.1

This directory contains the frozen foundational [specification].

The v0.1 [specification] defines:


- [immutable](glossary.md#Immutability) [observations](glossary.md#Observation),
- [deterministic](glossary.md#Determinism) [procedures](glossary.md#Procedure),
- [artifacts](glossary.md#Artifact),
- [uncertainty](glossary.md#Uncertainty),
- [provenance](glossary.md#Provenance),
- [conceptual interpretation layers](glossary.md#Prism).
- [executable-notation]
- [visual-reasoning]
- [projection-invariance](glossary.md#projection-invariance)

Implementation details are intentionally excluded.

The specification defines what implementations MUST satisfy.

[Architecture documents](../../docs/architecture/reference-api.md) define how implementations SHOULD be structured.
